# Сэтгэлийн Одод — Сэтгэл зүйн тестийн сан

Монгол хэл дээрх сэтгэл зүйн тестийн сан: хэрэглэгч бүртгүүлж, тестээ төлж
(6,500₮), тест өгч, үр дүнгээ шууд харна. Админ өөрийн `.docx` болон бусад
файлуудаа оруулж автоматаар тест болгон хувиргана.

Энэ бол **standalone** төсөл (Node + Express + React + PostgreSQL) — Muse
artifact биш. GitHub-д оруулж, Node + Postgres ажиллуулдаг хостинг дээр
байршуулна.

> **Анхааруулга:** GitHub Pages дангаараа энэ аппыг ажиллуулж чадахгүй —
> Pages зөвхөн статик хуудас үйлчилдэг. Нэвтрэх, төлбөр, оноо, үр дүн хадгалах
> нь сервер + өгөгдлийн сан шаарддаг тул Render / Railway / VPS гэх мэт
> Node + Postgres хост хэрэгтэй.

## Онцлог

- **Нэвтрэлт:** бүртгэл (нэр / нэвтрэх нэр / нууц үг), нэвтрэх. **Анх
  бүртгүүлсэн хэрэглэгч админ болно**, дараагийн бүх бүртгэл гишүүн.
  Админ эрх олгох үйлдэл сайтад байхгүй.
- **Тестийн сан:** гарчиг, зорилго (бүтэн тайлбар), ангилал, асуултын тоо,
  үнэ 6,500₮. Гүн ягаан hero, алтан амьдралын мод, ягаан-алтан өнгө,
  цөцгий/лаванда хэсэг, зүрх тэвэрсэн алтан од маскот. Утасанд ээлтэй.
- **Тестийн урсгал:** төлбөр → «Тестийн зорилго» дэлгэц (бүтэн тайлбар +
  асуултын тоо + заавар, «Тест эхлэх» товч) → асуултууд. Хариулт сонгоход
  ~0.45 секунд тодроод дараагийн асуулт руу автоматаар шилжинэ;
  «Өмнөх»/«Дараах» товч хэвээр; сүүлийн асуулт «Үр дүн харах»-аар дуусна.
  Үр дүн шууд гарч, «Миний үр дүн»-д хадгалагдана.
- **Төлбөр (QPay):** QPay тохируулаагүй үед төлбөрийн хуудас «Би төлсөн»-г
  **туршилтын баталгаажуулалт** гэж тодорхой тэмдэглэнэ. QPay merchant
  мэдээлэл оруулсан үед жинхэнэ QR үүсгэж, төлбөрийг зөвхөн QPay-ийн
  `/payment/check` бүрэн дүнг баталгаажуулсны дараа тооцно. Үнэ 6,500₮,
  QPay шимтгэл 1% (65₮, цэвэр 6,435₮).
- **Оноо:** сонголт бүрд оноо; нийлбэр оноо болон түлхүүрт суурилсан
  хэмжүүрүүд (тийм/үгүй асуултын дугаар + коэффициент, дэд хэмжүүр + нийт),
  онооны мужаар үр дүнгийн бүлэг. MMPI маягийн түүхий түлхүүрийн оноо —
  K-засвар хийдэггүй.
- **Админ самбар:** файл оруулж автоматаар импортлох — `.docx` (Word
  хүснэгтийг хадгална: асуултын хүснэгт, онооны түлхүүрийн хүснэгт, үр
  дүнгийн мужны хүснэгт), `.doc`, `.txt`, `.md`, `.csv`, `.json`, `.pdf`,
  `.xlsx`, `.pptx`, `.odt`, `.rtf`, `.html`, `.epub`, зураг (`.jpg`/`.png`,
  OCR боломжтой бол). Файлын доторх зураг асуултад хавсарна. Мөн загвар
  татах + текст буулгаж оруулах. Тест засах / нуух / устгах, хэрэглэгчийн
  жагсаалт, QPay тохиргоо (client id/secret, invoice code, merchant id).
- **Жишээ тест:** суулгахад «Сэтгэлийн тэнцвэр — жишээ тест (DEMO)» гэсэн
  3 асуулттай жишээ тест орно. Эзний бодит тестүүд энэ репод байхгүй —
  байршуулсны дараа админ самбараар `.docx` файлуудаа дахин оруулна.

## Технологи

- Сервер: Node 20+ / TypeScript / Express 4 / Drizzle ORM / PostgreSQL 16
- Клиент: React 18 / Vite 5 / TypeScript (production-д Express статик үйлчилнэ)
- Нэвтрэлт: bcryptjs + opaque session token (DB-д хадгална)
- Файл задлан: jszip, fast-xml-parser, mammoth, pdf-parse, xlsx, cheerio,
  csv-parse, word-extractor

## Орон нутагт ажиллуулах

Шаардлага: Node.js 20+, PostgreSQL 16 ажиллаж байх.

```bash
git clone <repo-url> setgeliin-odod
cd setgeliin-odod
npm install

cp .env.example .env
# .env дотор DATABASE_URL болон SESSION_SECRET-ээ оруулна

npm run db:migrate   # drizzle/*.sql шилжилтүүдийг хэрэглэнэ
npm run db:seed      # DEMO жишээ тестийг оруулна (сан хоосон бол)

npm run dev          # сервер :3001 + Vite клиент :5173 (proxy /api)
# эсвэл production маягаар:
npm run build
npm start            # http://localhost:3001
```

Эхлээд бүртгүүлсэн хэрэглэгч админ болно. Дараа нь админ самбараар
өөрийн тестүүдээ оруулна.

`.env` файлыг GitHub-д хэзээ ч оруулахгүй (`.gitignore`-д байгаа). Сервер
`.env` файл ачаалдаггүй (dotenv байхгүй) — `set -a; source .env; set +a`
гэж ачаалж ажиллуулна, эсвэл хувьсагчуудаа export хийнэ.

## Байршуулах (deploy)

### Render (санал болгож буй хялбар зам)

1. Render дээр PostgreSQL үүсгэнэ (Free tier болно).
2. Web Service үүсгэж энэ репогоо холбоно:
   - Build Command: `npm ci && npm run build`
   - Start Command: `npm run db:migrate && npm start`
   - Environment: `DATABASE_URL` (Postgres-ийн Internal Database URL),
     `SESSION_SECRET` (урт санамсаргүй утга).
3. Deploy дуусахаар өгсөн холбоосоор орж, бүртгүүлж (анхны хэрэглэгч =
   админ), админ самбараар тестүүдээ оруулна.

### Railway

1. Railway төсөлд PostgreSQL нэмнэ.
2. Энэ репогоо Deploy хийнэ; `DATABASE_URL` автоматаар орж ирнэ.
3. `SESSION_SECRET` хувьсагч нэмж, Start Command нь дээрхтэй ижил.

### VPS / өөрийн сервер

```bash
# Node 20+ болон PostgreSQL суулгасан байна гэж үзнэ
git clone <repo-url> && cd setgeliin-odod
npm ci && npm run build
# .env үүсгэж DATABASE_URL / SESSION_SECRET оруулна
npm run db:migrate && npm run db:seed
npm start
# Production-д pm2 / systemd ашиглахыг зөвлөнө
```

### Docker

```bash
docker build -t setgeliin-odod .
docker run -p 3001:3001 \
  -e DATABASE_URL=postgres://... \
  -e SESSION_SECRET=... \
  setgeliin-odod
# Шилжилт: docker run ... node dist/server/src/migrate.js
```

`.github/workflows/ci.yml` нь push бүрт `typecheck` + `build` шалгана.

## QPay тохиргоо

1. QPay merchant-аар бүртгүүлнэ: хувь хүн бол `qr.qpay.mn`, байгууллага бол
   `business.qpay.mn` — эсвэл Хаан банкны салбар дээр «QPay мерчантын
   гэрээ байгуулах» гэж хэлнэ. **Элсэлтийн болон суурь хураамжгүй**,
   гүйлгээ бүрд 1% шимтгэл авна.
2. QPay-аас авсан username, password, merchant ID, invoice code-оо админ
   самбарын «QPay тохиргоо» хэсэгт оруулна (эсвэл орчны хувьсагчаар
   `QPAY_CLIENT_ID` / `QPAY_CLIENT_SECRET` / `QPAY_INVOICE_CODE` /
   `QPAY_MERCHANT_ID` гэж тохируулна — орчны хувьсагч давуу эрхтэй).
3. Үүний дараа төлбөрийн хуудсанд жинхэнэ QR гарч, төлбөр нь QPay-ийн
   `/payment/check` бүрэн дүнг баталгаажуулсны дараа л тооцогдоно.
   Тохиргоо хоосон үед «Би төлсөн» нь зөвхөн туршилтын баталгаажуулалт
   хэвээр байна.

## Файл оруулах формат

### Текст хэлбэр (paste / .txt / .md)

```text
Тестийн гарчиг
Тайлбар: Тестийн зорилго энд бичигдэнэ.
Ангилал: Ерөнхий
1. Эхний асуулт?
а) Эхний сонголт (0 оноо)
б) Хоёр дахь сонголт (1 оноо)
в) Гурав дахь сонголт (2 оноо)
2. Хоёр дахь асуулт?
а) Тийм
б) Үгүй
Үр дүн:
0-1: Тайван — Стресс бага түвшинд байна.
2-4: Дунд зэрэг — Стресс дунд зэрэг байна.
```

Тайлбар: гарчиг нь эхний мөр; сонголтын оноо `(N оноо)` / `(N)` / `[N]` /
`→ N` гэж төгсгөлд нь бичигдэнэ; Тийм/Үгүй асуултад оноо бичээгүй бол
Тийм=1, Үгүй=0 гэж тооцно; `Үр дүн:` хэсгийн `0-1: Гарчиг — тайлбар`
мөрүүдээс үр дүнгийн бүлэг үүснэ. Хэмжүүрийн түлхүүр:

```text
Хэмжүүр:
Сэтгэл хөдлөл: тийм 1, 5, 9; үгүй 2, 6; коэффициент 2
```

### .docx

Асуултууд дугаарласан догол мөр эсвэл хүснэгтээр байж болно; асуултын
хүснэгт (№ / Асуулт / сонголтын баганууд), онооны түлхүүрийн хүснэгт
(хэмжүүр / тийм асуултууд / үгүй асуултууд / коэффициент), үр дүнгийн
мужны хүснэгт (муж / гарчиг / тайлбар) автоматаар танигдана. Догол мөр
болон хүснэгтийн асуултууд баримтын дарааллаар нэгтгэгдэнэ. Файлын
доторх зураг асуултад хавсарна.

### .json

```json
{
  "title": "Тестийн гарчиг",
  "description": "Зорилго",
  "category": "Ерөнхий",
  "questions": [
    { "text": "Асуулт?", "options": [{ "text": "Тийм", "score": 1 }, { "text": "Үгүй", "score": 0 }] }
  ],
  "scoring": { "mode": "sum", "bands": [{ "min": 0, "max": 1, "title": "Бага", "description": "..." }] }
}
```

### Бусад

`.pdf` (текст задлах), `.xlsx` (эхний хуудас = асуулт; `Түлхүүр` болон
`Үр дүн` хуудас = хэмжүүр/муж), `.pptx`, `.odt`, `.rtf`, `.html`, `.epub`,
`.csv` — текст задлангийн дараа дээрх текст хэлбэрээр задлана.
`.jpg`/`.png` зурагнаас OCR хийхийн тулд `tesseract.js` хэрэгтэй — энэ
хувилбарт суулгагдаагүй тул зураг оруулахад тодорхой Монгол хэл дээрх
мэдээ гарна (сүлжээний ерөнхий алдаа биш).

## Төслийн бүтэц

```
setgeliin-odod/
  client/            React + Vite клиент (Mongolian UI)
    src/api.ts       API клиент
    src/pages/       Нүүр / Нэвтрэх / Тест / Миний үр дүн / Админ
    src/components/  Алтан мод (SVG) + од маскот (SVG) — эх загвар
  server/
    src/index.ts     Express апп (API + статик клиент)
    src/routes.ts    Бүх API endpoint
    src/auth.ts      Бүртгэл/нэвтрэлт/сесс
    src/qpay.ts      QPay Merchant API
    src/scoring.ts   Оноо тооцоолох дүрэм (sum + scales)
    src/import/      Файл импортлогчид (docx хүснэгт хадгална)
    src/schema.ts    Drizzle схем
    src/seed.ts      DEMO тест
  shared/src/types.ts  Клиент/серверийн нийтлэг төрөл + API гэрээ
  drizzle/           SQL шилжилтүүд (0001_init, 0002_add_purchase_qr)
  uploads/           Оруулсан зургууд (git-д орохгүй)
```

API endpoint-үүдийг `server/src/routes.ts`-ээс, төрлүүдийг
`shared/src/types.ts`-ээс харна уу.

## Утасны APK

Энэ апп сервер + өгөгдлийн сан шаарддаг тул **офлайн APK болохгүй**.
Боломжтой зам: аппыг дээрх заавраар байршуулж нийтийн холбоостой болгоод,
тэр холбоосыг WebView-гоор боосон APK хийх (Capacitor эсвэл Android
WebView wrapper). APK интернет шаардана. GitHub Actions-аар APK барих
workflow нь байршуулсан холбоос бэлэн болсон үед нэмж болно.

## Мэдэгдэж буй хязгаар

- Жинхэнэ QPay төлбөрийн урсгал merchant бүртгэлтэйгээр шалгагдаагүй —
  туршилтын горим болон QPay API дуудлагын бүтэц хэрэгжсэн.
- `.doc` болон `.pdf` импортлогчийн код бичигдсэн ч бодит `.doc`/`.pdf`
  файлаар эцсийн шалгалт хийгдээгүй (текст задлах зам нь `.txt`-тэй ижил).
- Зурагнаас OCR хийхэд `tesseract.js` суулгагдаагүй — зураг оруулахад
  тодорхой Монгол мэдээ гарна.
- 390px гар утасны харагдац нь CSS дүрмээр шалгагдсан, хөтөч дээр шууд
  render хийж шалгаагүй.
- `multer` 1.x ашигласан (2.x руу шилжих боломжтой — npm анхааруулга өгдөг).
